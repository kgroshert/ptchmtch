# Chords Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a third mode, **Chords**, to the Audiation page. A chord or interval sounds and stops,
then the singer sings its notes from memory. It has six levels, two contexts (*On their own* and
*In a key*), and its own History tab.

**Architecture:** All chord content lives in a new pure module, `src/chords.ts`: levels, chord
generation for both contexts, prompts, and note, chord and syllable names. It is checked offline
with tsx. `EchoTrainer` (`src/echo.ts`) gains the mode `"chords"`, which reuses Echo's round flow,
`judgeAnswer`, level staircase, note map and result. The chord-specific display hooks into the
existing code paths, and Echo and Syllables stay unchanged.

**Tech Stack:** Vite + TypeScript, Web Audio (`host.play` with `midi: number[]` for chords),
localStorage, tsx checks (`npm run check`).

**Spec:** `docs/superpowers/specs/2026-11-19-chords-design.md`

## Global Constraints

- **No commits.** The user commits only on request, so each task ends with a checkpoint (type check
  and checks pass).
- **Work on a branch** `chords` (switch to it before Task 1).
- **Echo and Syllables must not change** in behaviour or scoring. `npm run check` must stay green.
- **The prompt never names notes or syllables:** only "bottom to top", "the low note, then the high
  one", "the top / bottom / middle note".
- **The result always names the notes and the chord** (e.g. "F – A – C", "F major"). In a key it
  adds the syllables and the step (e.g. "fa – la – do", "IV").
- **Judging is octave-exact** in Chords: pass `{ ...settings, octaveFree: false }` to `judgeAnswer`.
- **Every chord lies within the voice's comfortable range** (`VOICES[v].low..high`, inclusive).
- **The chord stops before singing.** *Hear again* replays it, and the round still counts.
- **Minor is la-based**, with *si* for the raised 7th. The key mode's V and V7 in minor use the
  raised 7th.
- **The context setting** is saved in the Echo prefs as `chordContext: "free" | "key"` (default
  `"free"`). The chord level is `chords?: LevelState`.
- **History:** key `"ptchmtch.chords.sessions"`, tab id `"chords"`, label `Chords`.

## Review Focus

1. **Narrow voice ranges.** A bass (41–60) with an octave or a seventh chord, in any key, must always
   fit within the range and never loop forever. Test: `fits every voice` (Task 1).
2. ***Hear again* while singing.** The piano must not be judged as the answer: the answer restarts
   after the chord. Browser check in Task 2.
3. **The octave-free setting switched on.** Chords is still octave-exact, so a note sung an octave
   off counts as wrong. Browser check in Task 2.
4. **Minor key spelling.** The V chord in A minor contains G♯, named *si*, and III is C major. Test:
   `minor key chords` (Task 1).
5. **Switching back from Chords to Echo.** Echo keeps its own level, title, settings visibility and
   phrase playback. Browser check in Task 2.

### Task 1: `src/chords.ts`, the chord content (pure)

**Files:**
- Create: `src/chords.ts`, `scripts/check-chords.ts`
- Modify: `package.json` (`check` also runs `tsx scripts/check-chords.ts`)

**Interfaces:**
- Produces:

```ts
export type ChordContext = "free" | "key";
export interface ChordLevel { label: string; gap: number } // gap: seconds of silence before singing (1.0 for every level)
export const CHORD_LEVELS: ChordLevel[];                    // 6, in the spec's order
export function describeChordLevel(i: number): string;      // e.g. "3: major and minor chords, bottom to top"
export interface ChordSetup { context: ChordContext; low: number; high: number; key: number; minor: boolean }
export interface ChordRound {
  notes: number[];               // MIDI, bottom to top: what sounds
  targets: number[];             // MIDI, what to sing, in order
  prompt: string;                // "Sing them bottom to top" | "Sing the low note, then the high one" | "Sing the top note" | "Sing the bottom note" | "Sing the middle note"
  name: string;                  // "Major third", "F major", "F major, first inversion", "G7", "Cmaj7", "Dm7"
  noteNames: string[];           // per entry of `notes`, pitch class only: ["F", "A", "C"]
  syllables: string[] | null;    // per entry of `notes`, key mode only: ["fa", "la", "do"]
  step: string | null;           // key mode only: "IV", "vi", "V7", "IIImaj7"
}
export function chordRound(level: number, setup: ChordSetup, rand?: () => number): ChordRound;
```

- **Level content.** Indices are 0-based. Free means *On their own*; key means *In a key*.
  - **L0:** intervals: major or minor third, perfect fifth, octave.
    - Free: on a random root.
    - Key: built on scale degrees (a diatonic third, fifth or octave).
  - **L1:** any interval from minor second to octave.
    - Key: any diatonic interval from a second to an octave.
  - **L2:** major or minor triads in root position.
    - Free: random root.
    - Key: I, IV, V (major) or i, iv, V (minor).
  - **L3:** like L2, with a single target chosen at random: bottom, top or middle (the 3rd).
  - **L4:** first or second inversion, always inverted.
    - Free: random major or minor.
    - Key: from I ii iii IV V vi (major) or i III iv V VI (minor).
  - **L5:** seventh chords in root position.
    - Free: dominant 7, major 7 or minor 7 on a random root.
    - Key: V7, ii7, Imaj7, IVmaj7 (major) or V7, iv7, IIImaj7, VImaj7 (minor).
- **Voicing.** Close position: inverted notes are moved up an octave, and sevenths span a seventh.
  The bottom note is chosen at random among the placements where all notes lie in `[low, high]`.
  Key mode keeps the degree's pitch class.
- **Syllables** are counted from do = key (major) or key + 3 (minor):
  - 0 do, 2 re, 4 mi, 5 fa, 7 sol, 9 la, 11 ti;
  - 8 is *si* in minor (the raised sol).
- **Note names:** `midiName(m)` without the octave. The interval names are: minor/major second,
  minor/major third, perfect fourth, tritone, perfect fifth, minor/major sixth, minor/major seventh,
  octave.

- [ ] **Step 1: Write `scripts/check-chords.ts`.** It uses `rng`, `expect` and `done` from
  `scripts/check-util.ts`. For each check, run 300 rounds with `rng(seed)`:
  - `fits every voice`: for every `VOICES` entry × every level × keys 0–11 × major and minor × both
    contexts, `notes` and `targets` lie within `[low, high]`, and `chordRound` returns.
  - `targets in order`:
    - L0, L1, L2, L4, L5: `targets` equal `notes`;
    - L3: `targets.length === 1`, and the one target is `notes[0]`, `notes[2]` or `notes[1]`
      (matching the prompt's word: bottom, top or middle).
  - `prompts never name notes`: no prompt contains a note name, `do`, `re`, `mi`, `fa`, `sol`, `la`,
    `ti` or `si` as a word.
  - `free intervals`: at L0 the semitone gap is in {3, 4, 7, 12}; at L1 it is in 1–12.
  - `free triads`: at L2 the steps above the bottom note are [4, 7] or [3, 7]; at L4 they are
    [3, 8], [4, 9], [5, 9] or [5, 8].
  - `major key chords`: key C major at L2 gives only C, F or G major. `step` ∈ {I, IV, V} and
    `syllables` for IV are ["fa", "la", "do"].
  - `minor key chords`: key A minor (key 9, minor) at L2:
    - V has `noteNames` ["E", "G♯", "B"] and `syllables` ["mi", "si", "ti"].
    - iv has syllables ["re", "fa", "la"].
    - At L4, III is a C major chord (notes C E G in some inversion).
  - `sevenths`: at free L5 the steps are [4, 7, 10], [4, 7, 11] or [3, 7, 10]. In C major the name of
    V7 is "G7" and its syllables are ["sol", "ti", "re", "fa"].
  - `names`: for a free L2 chord on F major, `name === "F major"` and `noteNames` are
    ["F", "A", "C"].

### Task 2: The Chords mode in the Echo trainer

**Files:**
- Modify: `src/echo.ts`, `index.html` (Audiation section), `src/style.css`

**Interfaces:**
- Consumes `chordRound`, `CHORD_LEVELS`, `describeChordLevel`, `ChordRound` and `ChordContext` from
  Task 1.
- Produces:
  - `TrainMode = "echo" | "syllables" | "chords"`;
  - `EchoPrefs.chordContext?: ChordContext`;
  - `EchoPrefs.chords?: LevelState`;
  - `onSession(s, "chords")` for Chords sessions.

- [ ] **Step 1: HTML.**
  - In `#ecMode`, add `<button data-mode="chords" title="Hear a chord, sing its notes">Chords</button>`.
  - In the settings, add `<label id="ecChordCtxWrap">Chords <select id="ecChordCtx">` with the
    options `free` "On their own" and `key` "In a key".
  - In the stage, next to *Done*, add `<button id="ecHearAgain" class="btn ghost" hidden>Hear again</button>`.
  - In the result body, the chord line renders as `<p class="echo-chord">`, styled like `.echo-agree`.
- [ ] **Step 2: Mode wiring in `EchoTrainer`.**
  - **Level getters:** `lv` returns `prefs.chords ??= {fixedLevel:null, level:0}`. `levelCount` is
    `CHORD_LEVELS.length`, and `describe` is `describeChordLevel`.
  - **`showPrefs`:**
    - shows `#ecChordCtxWrap` only in Chords;
    - hides the Key and Tonality labels and `#ecKey` when Chords is *On their own*;
    - sets the title to "Chords" and the idle context to "Hear a chord, keep it in mind, sing its
      notes".
  - **Settings changes:** `ecChordCtx` change → `onChange(true)`.
  - **`start()`:** in Chords *On their own* there's no `playKey`, and the first round starts after
    0.5 s. The context line is "On their own · {voice}", or "{key name} · {voice}" in a key.
  - **Idle hint (Chords):** "You'll hear a chord (or two notes at once). It stops; keep it in mind,
    then sing its notes as asked."
  - **Hold and sing texts:** the hold phase reads "Hold it in your mind…". The sing phase's
    `#ecPhase` is the round's `prompt`.
- [ ] **Step 3: The round.**
  - **New phrase:** in Chords, `round()` calls
    `chordRound(level, {context, low, high, key, minor})` for the voice's range.
    - Up to 10 tries if `notes.join()` equals the previous round's.
    - Then `this.chord = r` and `this.targets = r.targets`.
    - The hold gap is `CHORD_LEVELS[level].gap`.
  - **`playPhrase()` in Chords:** plays all of `chord.notes` at once for 1.5 s.
  - **Replay after the result:** plays the chord, then `chord.notes` one after another (`NOTE_SEC`
    each).
  - ***Hear again*:** visible in hold and sing in Chords.
    - In hold, it replays the chord and restarts the hold timer.
    - In sing, it discards the frames, goes back to hold, replays the chord, then `beginAnswer()`
      after the gap.
    - It doesn't change `counts`.
  - **Judging:** in Chords, `finishAnswer()` judges with `{ ...this.host.settings(), octaveFree: false }`.
- [ ] **Step 4: The result in Chords.**
  - A line above the rows: "{name} · {noteNames joined with " – "}". In a key it continues with
    "· {step} · {syllables joined with " – "}".
  - Each row's label is the target's syllable in a key, or empty on their own, instead of
    `degreeSyl(degs[i])`. The note name stays in the row.
  - `stats.mode = "chords"`.
- [ ] **Step 5:** Run `npx tsc --noEmit && npm run check`.
  - Expected: both pass.
- [ ] **Step 6: Browser check** (`preview_start` "dev"). Fake the mic with an oscillator whose
  frequency is set by script after the chord. Back up `localStorage` and restore it afterwards.
  - **On their own, L2:**
    - the chord sounds (check through a `host.play` spy that `midi` is an array of 3);
    - sing its three notes in order → "All right and in tune", with the chord line shown;
    - the replay is chord, then arpeggio.
  - **In a key, L3:** the prompt names one voice. Singing it gives one row with its syllable, and
    the line includes the step.
  - ***Hear again* during singing:** back to hold, the chord plays again, and the answer starts
    after it. Review Focus 2.
  - **Octave-free on (Settings):** singing the target an octave lower → the note is wrong. Review
    Focus 3.
  - **Switch back to Echo:** Echo's title, level select, Key and Tonality settings and phrase
    playback (one note at a time) are as before. Review Focus 5.
  - **375 px wide:** the mode switch with three buttons fits without horizontal scroll.
